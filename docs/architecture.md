# TrustGraph AI Architecture

## 1. System Overview
**TRUSTGRAPH AI** is an AI-based fake Indian government job and recruitment scam detection system designed around the core principle:

> **"We don't trust the message; we trust the evidence."**

Instead of relying on a superficial text-to-sentiment or naive text-to-scam pipeline, TrustGraph AI grounds classifications upon deterministic institutional evidence, digital feature representations, knowledge graph topology, and multi-factor contradiction reasoning.

## 2. Multi-Stage Architectural Pipeline
```
               [ User Input ]
        (Text, Image, PDF, URL, Presets)
                      ↓
           [ Evidence Extraction ]
   (Org, Advt No, Fees, UPI, QR, Phone, Domain)
                      ↓
             [ AI Understanding ]
    (NLP Intent, Urgent Coercion, Vision Preprocessing)
                      ↓
            [ Recruitment DNA ]
        (9-Dimensional Digital Genome)
                      ↓
            [ Evidence Graph ]
      (Entities & Attributed Knowledge Graph)
                      ↓
    [ Official Recruitment Knowledge Base ]
    (UPSC, SSC, RRB, India Post, State PSCs)
                      ↓
          [ DNA + Graph Matching ]
      (Pattern Similarity & Structure Alignment)
                      ↓
         [ Scam Network Analyzer ]
      (Repeated Phones, UPI IDs, Host Domains)
                      ↓
       [ Contradiction & Risk Reasoning ]
    (Deterministic Protocol Violation Rules)
                      ↓
       [ ML Risk Prediction & Arbiter ]
      (Feature Pipeline + Safety Overrides)
                      ↓
             [ Explainable AI ]
    (Positive Supporting vs Negative Risk Factors)
                      ↓
      [ Case / Scam Intelligence Store ]
```

## 3. Key Components
1. **Recruitment DNA Generator**: Encodes 9 independent digital feature signatures:
   - Organization Signature
   - Notification Signature
   - Domain Signature
   - Contact Signature
   - Visual Signature
   - Writing Signature
   - Layout Signature
   - Payment Signature
   - Temporal Signature
2. **Evidence Graph**: Represents entities (Organization, Notification, Domain, Email, Phone, QR, UPI) and relationships (`PUBLISHED_BY`, `USES_DOMAIN`, `USES_EMAIL`, `CONTACTED_BY`, `HAS_QR`, `REQUESTS_PAYMENT`, `CONNECTED_TO`).
3. **Scam Network Analyzer**: Cross-checks repeated fraud infrastructure across historical cases.
4. **Deterministic Safety Arbiter**: Guarantees that ML models cannot silently override critical verified evidence (e.g. personal UPI fee collection or non-governmental domains impersonating central commissions).
